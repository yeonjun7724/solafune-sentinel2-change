Solafune Change Analyzer

Quick start

  1. Open the dock (toolbar icon or Plugins > Solafune Change Analyzer).
  2. On the Inputs tab, pick the before/after Sentinel-2 folders (each must contain B02/B03/B04 as GeoTIFF or JP2), an AOI vector file, and an output directory.
  3. Click Validate Inputs. Fix any errors shown before continuing.
  4. Configure Change Detection and, optionally, Spatial Analysis.
  5. Check the Dependencies tab: if "Embedded QGIS Python" is not ready (common on Windows/OSGeo4W installs, which do not ship rasterio/scikit-learn/libpysal by default), point "External interpreter" at a Python environment that has the CLI's dependencies installed (e.g. this project's .venv).
  6. Click Run Analysis on the Run & Results tab.

Supported input structure

before_folder/
  B02.tif (or *_B02*.tif / *_B02*.jp2)
  B03.tif
  B04.tif
after_folder/
  B02.tif
  B03.tif
  B04.tif

Band 2 = Blue, Band 3 = Green, Band 4 = Red. NDVI is not computed anywhere in this plugin because no NIR band (B08) is required or read.

Methods

  • Provided baseline: an independent reimplementation of the assignment's example algorithm (per-pixel Euclidean distance across bands, min-max normalized). No radiometric normalization; a single extreme pixel can compress the whole intensity scale.
  • Robust RGB CVA: per-band differences standardized with median/MAD, combined as sqrt(sum(z_b^2)). This is the primary, recommended method.

Threshold methods

Otsu (automatic bimodal threshold), Percentile (a chosen percentile of the valid-pixel intensity distribution), or Manual (an absolute value you supply).

Spatial statistics

  • Global Moran's I: is change intensity spatially autocorrelated overall, versus what random spatial arrangement would produce (permutation test)?
  • Local Moran's I (LISA): per-cell High-High / Low-Low / High-Low / Low-High cluster membership.
  • Getis-Ord Gi*: statistically significant hot spots / cold spots of change intensity.
  • FDR correction: Benjamini-Hochberg adjustment of Gi* p-values, which controls the false discovery rate that arises from running one significance test per grid cell.

A Gi* p-value/q-value describes spatial pattern significance, not a probability that a given change is real mining activity - see the "confidence" field below.

Experimental spatial ML

Isolation Forest (anomaly ranking) or DBSCAN (spatial clustering) over the same analysis grid, using robust-scaled spectral/spatial-context features. There are no ground-truth labels for this AOI: outputs are an exploratory ranking, not a validated classifier, and no accuracy/precision/recall is computed. Stability is instead assessed via spatial block bootstrap (top-K anomaly overlap) and hyperparameter sensitivity - see the run's report.md.

Output layers

AOI, Before/After RGB, Baseline Intensity/Binary, CVA Intensity/Binary, Change Features (polygons), Analysis Grid, LISA Clusters, Gi* Hotspots, and (if ML is enabled) Spatial Anomalies - all grouped under "Solafune Change Analysis - <run id>" in the layer tree, styled with the bundled QML files.

GeoPackage tables

change_features and spatial_grid (real geometry columns), run_metadata (inputs, checksums, parameters, package version, seed), quality_checks (validation issues/warnings for that run).

The "confidence" field

confidence on each change feature is a documented 0-1 heuristic score (threshold excess + intensity consistency + patch size + hotspot significance + ML anomaly rank), not a calibrated probability of true change.

Limitations

  • No NDVI (no NIR band provided).
  • No cloud/shadow mask (no Scene Classification Layer provided).
  • Only two dates: seasonal vs. persistent change cannot be separated.
  • No ground truth: no accuracy claims anywhere in this plugin or its outputs.

Troubleshooting

  • "Embedded QGIS Python (missing dependencies)": expected on most Windows/OSGeo4W QGIS installs. Use the Dependencies tab to point at an external interpreter instead.
  • Run fails immediately: check the Run & Results log panel, then the detailed log referenced in the error dialog (QGIS Log Messages panel, "Solafune Change Analyzer" tab).
  • Nothing loads after a run: check "Load results into current QGIS project" is enabled on the Outputs tab, and that the output directory is writable.

Dependency setup (external environment)

cd path\to\solafune-sentinel2-change
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pip install -e .

Then in the Dependencies tab, browse to .venv\Scripts\python.exe and click "Check dependencies".
